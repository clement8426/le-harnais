# Compte rendu de réunion

Rédige le compte rendu en suivant exactement ce plan :

1. **En une phrase** : la décision ou le résultat principal.
2. **Décisions** : une ligne par décision, avec qui s'en charge.
3. **À faire** : une case à cocher par tâche, avec la personne et la date si elles sont connues.
4. **Prochaine réunion** : date et heure, si elles sont données.

Règles :

- N'invente rien. Si une information manque, écris « à préciser ».
- Pas plus de 200 mots.
- Les montants restent dans leur devise d'origine.
