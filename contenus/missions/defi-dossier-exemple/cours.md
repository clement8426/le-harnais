# Le défi final

Ton harnais est complet. Ce défi les enchaîne tous, sur un vrai cas (fictif) : le dossier de M. Jean Exemple, frontalier de Morteau, blessé au poignet au travail, dont l'assurance refuse de payer.

Les documents sont médicaux : pour ce défi, ton IA doit être **hébergée en Suisse (Infomaniak) ou tourner sur ton ordinateur**. Avec un fournisseur américain, la première preuve reste rouge.

## La consigne à donner à ton IA

Dicte-la avec le micro, ou écris-la :

```text
Traite le dossier de missions/defi-dossier-exemple/fichiers :
1. fais l'OCR de rapport-scan.pdf et transcris note-vocale.wav ;
2. rédige missions/defi-dossier-exemple/compte-rendu.md, une page pour l'assurance :
   les faits, les dates, ce qui est demandé. N'invente rien ; si une information manque, écris « à vérifier » ;
3. utilise ma skill compte-rendu si elle s'applique ;
4. lis-moi un résumé audio de moins d'une minute.
```

## Ensuite

1. Accepte les demandes une par une, en lisant chaque commande.
2. Relis le compte rendu **avec le scan sous les yeux** : la date de l'accident, le côté blessé, le témoin, le délai d'opposition.
3. Écoute le résumé.

> **À retenir** : tu sais maintenant ce qu'il y a derrière une IA qui « sait tout faire » : un cerveau, des outils, un harnais, et toi qui décides.
