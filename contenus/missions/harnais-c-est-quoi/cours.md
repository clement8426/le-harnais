# Qu'est-ce qu'un harnais ?

Claude, ChatGPT ou ton harnais ont l'air de tout savoir faire. En réalité, ils sont faits de trois pièces.

```text
  Toi  →  le harnais  →  le cerveau (le modèle)
              ↓
          les outils : terminal, fichiers, navigateur, voix…
```

- **Le cerveau** est le modèle : Opus, Sonnet, GPT, Llama, Mistral. Il lit du texte et en écrit. C'est tout.
- **Les outils** agissent : lire un fichier, lancer une commande, ouvrir une page, écouter ta voix.
- **Le harnais** est le logiciel qui relie les deux. Il donne au cerveau la liste des outils, exécute ceux qu'il demande, et lui renvoie le résultat. Claude Code en est un. Celui que tu as sous les yeux aussi.

Pour l'instant, ton harnais n'a aucun outil : ton IA peut seulement discuter. Chaque mission va lui en ajouter un.
